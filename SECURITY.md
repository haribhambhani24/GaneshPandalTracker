# Security Policy

## Reporting Security Vulnerabilities

We take the security and integrity of Ganesh Pandal Tracker and its user community seriously. If you discover a security vulnerability or potential threat in this application, please report it responsibly and privately.

### How to Report

Please **do not** report vulnerabilities through public GitHub issues, discussions, or social media.

Instead, please send an encrypted or detailed report directly to:
**`contact@example.com`**  
*(or the designated contact email configured in `src/config/site.ts`)*

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce the behavior safely.
3. Relevant URLs, endpoints, or environment details.

### Response Commitment

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will coordinate remediation without disclosing details publicly until a fix is released.
- Responsible disclosure is deeply appreciated.
