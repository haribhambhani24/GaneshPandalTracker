# Contributing to Ganesh Pandal Tracker

Thank you for your interest in Ganesh Pandal Tracker.

### Proprietary Project Notice

**Ganesh Pandal Tracker is a proprietary, closed-source project.** 
The source code is hosted publicly on GitHub strictly for transparency, evaluation, and portfolio demonstration purposes.

- **External Pull Requests**: We do **not** accept external pull requests, code contributions, or unsolicited feature modifications. Any pull requests submitted will be closed without review.
- **Forks and Redistribution**: Creating forks for the purpose of redeploying, copying, mirroring, sublicensing, or creating derivative works of this application, its interface, or its dataset is strictly prohibited under the project's [LICENSE](./LICENSE).
- **Bug & Issue Reports**: Devotees and users who encounter bugs or accessibility issues are welcome to report them via the in-app "Report a Problem" modal on any pandal page, or privately by email to `contact@example.com` (or the email listed in `src/config/site.ts`).
